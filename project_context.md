# PROJECT_CONTEXT.md

# Project Name

digital mazdoor app

---

# Problem Statement

The informal economy relies heavily on:

* WhatsApp
* phone calls
* referrals
* informal communication

This creates:

* poor service discovery
* unreliable matching
* missed opportunities
* weak follow-up
* inefficient workflows

Users struggle to:

* find trusted providers
* get real-time availability
* compare providers intelligently
* manage bookings efficiently

---

# Project Goal

Build an Agentic AI System that automates the complete lifecycle of service requests.

The system should:

1. Understand multilingual user requests
2. Discover providers
3. Rank providers intelligently
4. Simulate bookings
5. Automate follow-ups
6. Handle disputes
7. Show reasoning traces

---

# Example User Input

“Mujhe kal subah Gulshan mein AC technician chahiye budget kam hai”
